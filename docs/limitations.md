# 已知问题与验证范围

## 并发与容量

已验证本机两个独立浏览器会话，以及双线程开考、提交和心跳的数据一致性。未进行持续高负载、大量用户集中注册或交卷、分布式负载测试，因此没有最大并发用户数、吞吐量或延迟指标。

同手机号先后重复注册已有手工及自动化测试，账号唯一性由数据库约束保证。同手机号同步竞争注册尚未单独测试，锁等待和资源耗尽时的表现也未验证。

SQLite 的写操作需要竞争锁；注册和登录的密码计算、每秒心跳和磁盘性能都可能影响负载能力。正式扩大使用规模前，需要在独立环境中进行分级压测，并评估限流、错误恢复和数据库方案。

## 作答与计时

已提交答案、场次和服务器确认的剩余时间会保存，当前题未提交的选择没有草稿自动保存。每个账号每套试卷只有一个场次，交卷后不能重考。

连接中断后保留已确认的余额。心跳间隔超过 4 秒时按中断处理，不足一次心跳的时间可能未计入；故意刷新、断网或浏览器后台节流可能获得额外思考时间。这一方案优先保障续考，不提供完整防作弊能力。

旧数据没有在线作答时长记录，升级后首次恢复时，当前未提交题会按快照初始化一次时限；已提交答案及完成状态不回退。

最后一题已保存但响应丢失时，重试会收到已结束提示，刷新后可恢复完成页。该分支尚未增加专门的即时恢复交互。

## 部署与功能

本次实测环境为 Windows，自动化浏览器为 Chromium。手工测试使用两个浏览器完成小规模并行操作；尚未完成其他操作系统、移动端和多浏览器兼容矩阵验证。

未进行公网 HTTPS、多机部署、长期稳定性、磁盘损坏或断电容灾测试。首次安装依赖需要访问相应下载源。

手机号只做格式校验，不验证归属或发送短信。系统未提供找回密码、登录限流、会话自动清理、题库管理页面、复杂评分和完整生产监控。同一账号多设备使用及异常行为识别未作为本次功能实现。

自动化使用独立数据和服务，但仍共享本机硬件资源。在考用户使用期间不应进行依赖重装、业务源码修改、服务重启或系统级断网操作。
