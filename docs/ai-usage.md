# AI 工具使用说明

本项目使用 Codex 桌面应用中的编码助手，完成已有工程阅读、业务范围梳理、Python/FastAPI/SQLite 后端实现、前端对接、测试、调试和文档编写。

当前会话未调用其他 AI 写作、图像工具或子代理。可读取的会话宿主元数据记录模型标识为 `gpt-6.1-sol`、提供方为 `openai`，并记录宿主 `cli_version=0.166.0-alpha.5.1`；这不是对底层权重修订版或桌面应用版本的推断。各会话段的实际元数据和时间范围保存在 `docs/ai-records/manifest.json`。

## 人的决策与约束

用户确认使用 Python + FastAPI + SQLite，要求逐项实现并验证此前讨论的测试场景，自主执行、使用 Git 保存版本，以及严禁修改工作区以外文件。

用户选择加分题 1，自行录制 7 个手动测试视频，发现并报告断网刷新时的计时问题，确认原业务应保留剩余预算后要求修复，关闭网页后明确授权合并启用。最终交付阶段由用户提出完整流程、数据一致性和多用户稳定性为重点，并要求如实呈现资源和验证边界；材料将“尚未进行容量/同手机号竞争注册实验”与“技术上不能本地模拟”区分。

AI 负责工程梳理、方案及代码、隔离自动化、调试和材料编排；用户的手工操作结果与自动化结果分别保存，不把 AI 生成的说明当作用户实际执行过的证明。本轮只做材料整理、录屏抽帧核对、证据校验和打包，没有在活动服务上追加功能测试或压测。

## 完整可见对话与工具记录

本文件是工具清单和用途说明，**不是完整 AI 对话记录**。本次已从当前聊天对应的本地会话段只读导出可见输入、助手回复、工具调用与输出，按各段原有时间顺序保存到 `docs/ai-records/`：JSONL 保留结构，Markdown 方便阅读，manifest 标明来源快照哈希、记录数量、模型元数据及截止时间。多个恢复段可能包含继承的重复上下文，分别完整保留，不精选片段，也不以摘要代替原记录。

用户原始导出保留原格式和字节；分段工具导出另作必要手机号/邮箱脱敏，二者不互相覆盖。原导出里可见的工具摘要不能代替可获取的完整工具输出，因而补充记录一并入库。

后续用户撤回含个人信息的旧并行视频，三张衍生截图亦按必要脱敏规则从工具记录及本地待发布历史中清除；其余对话与失败过程保留，见 [隐私修订说明](privacy-cleanup.md)。

手机号一致映射为脱敏标签，邮箱脱敏；保留失败尝试和后续调整。不导出系统/开发者指令、内部推理、token 计数或重复的宿主通知，这些不是用户可见对话。可见消息和工具记录不做内容摘要。

该聊天仍在进行，快照不能包含导出之后才发生的新消息（包括后续最终回复）。**最终提交前应再运行导出命令或从应用保存完整会话，覆盖 manifest 截止时间之后的内容。** 可复用 `scripts/export-ai-records.py --source 会话JSONL路径`，每个相关源文件使用一个 `--source`，输出默认限定在本项目 `docs/ai-records/`。该脚本只读取外部会话文件，不修改它们。

本机刷新当前聊天记录可执行 `./scripts/export-current-chat.ps1`；它只匹配当前聊天 ID 对应的会话段，并只写入项目内导出目录。其他机器没有这些本地源文件时，使用应用的完整导出或完整分享记录。

如果另有聊天或其他 AI 工具参与本次笔试，提交者仍需补齐对应完整记录和清单。不能把已导出的会话段错误描述为其他尚未提供会话的记录。
