# AI 工具使用说明

本项目使用 Codex 桌面应用中的编码助手，完成已有工程阅读、业务范围梳理、Python/FastAPI/SQLite 后端实现、前端对接、测试、调试和文档编写。

当前会话未调用其他 AI 写作、图像工具或子代理。该会话没有提供可核实的具体模型版本标识，因此不虚构型号；提交者可从工具的会话详情补充实际可获取的信息。

## 人的决策与约束

用户确认使用 Python + FastAPI + SQLite，要求逐项实现并验证此前讨论的测试场景，自主执行、使用 Git 保存版本，以及严禁修改工作区以外文件。

## 实施记录位置

- Git 分支：`feature/python-backend-tests`；提交历史保留后端、前端和测试、文档等阶段。
- 自动化测试源码：`backend/tests/`、`tests/e2e/`。
- 实际结果：`docs/verification.md` 及 `docs/reports/`。
- 依赖、临时文件、测试浏览器、数据库和日志限制在工作区，未修改全局 Python 或全局 Git 配置，未推送远程。
