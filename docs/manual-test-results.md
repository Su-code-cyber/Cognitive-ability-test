# 用户手动测试结果与录屏索引

本页整理用户自行操作并放入 `docs/reports/` 的 7 个原始 MP4。文件保持原内容，不剪辑、不改名；视频时长、格式、长度和 SHA-256 记录在 [录屏清单](reports/manual-video-manifest.json)。本轮整理通过关键时间点抽帧核对可见页面，不把抽帧核对描述成逐帧、音轨或数据库审计。

这些录屏没有嵌入准确 Git 提交号，不强行指定拍摄时的代码版本。部分欢迎页仍展示早期计时文案，因此作为实际手工操作的历史证据保留；新版断网暂停规则以独立的最新自动化报告、截图和设计说明为准。

## 与自动化证据的分工

手工视频没有单独展示刷新/重新登录后剩余时间的精确比较、实际停止后端并重启、非法跨用户访问、全部六题正常完成后的数据库结果、相同请求的竞争执行，以及新版断网恢复全过程。这些项目中已有自动化记录的，分别见 [验收对应表](acceptance-matrix.md) 和 [最新报告](reports/offline-timer/summary.json)，不虚构额外手工结果。

用户在手动断网刷新时报告了当前题被消耗时间、重连可能跳题的问题。该反馈没有独立 MP4，但完整可见会话保留了报告及后续修复过程，自动化随后复现并验证长断网、离线刷新和后端不可达的恢复规则。不能声称这 7 个录屏包含新版断网回归。

两浏览器正常操作不等于高并发压测。当前证据不能证明大量用户同时登录、每秒心跳、集中交卷或同手机号同时注册时的性能和稳定性；该边界见 [limitations.md](limitations.md)。

## 交付方式

原始录屏以普通 Git 文件随最终源码仓库交付，评审克隆后可直接用支持 MP4/H.264 的播放器打开。录屏中保留测试表单和浏览器界面；文档不重复列出其中账号或密码。没有将本机数据库、登录 Cookie、浏览器个人资料或密码存储导出加入仓库。
