# 验收说明

按 README 安装依赖、初始化数据库并启动服务后，使用两个独立浏览器会话和不同账号进行验收。

## 基本题

| 验收项目 | 操作与预期结果 | 已有验证 |
| --- | --- | --- |
| 初始化与启动 | 新数据库可建表并生成含单选、多选的示例卷，重复初始化不重复插入 | 新 SQLite、种子重复运行及本机启动 |
| 注册、登录、退出 | 新用户自行注册；退出后可登录；重复注册、错误密码及未登录请求被拒绝 | 手工录屏、接口及浏览器完整流程 |
| 用户隔离 | A 提交到下一题时 B 保持自身进度；使用对方场次访问、提交或交卷被拒绝 | 两浏览器录屏及跨用户接口测试 |
| 答题与正常交卷 | 单选选择一项，多选选择多项，提交后推进；末题完成后显示成功，数据库可查到答案 | 手工作答、并行录屏、六题完整自动化及数据库断言 |
| 刷新与续考 | 已提交进度保留，恢复原题及剩余时间；在线超时切题，断网恢复不丢当前题 | 手工刷新录屏及计时、离线刷新自动化 |
| 提前交卷与结束状态 | 中途确认交卷后进入完成页；结束后再次答题不能修改已有记录 | 手工提前交卷及正常/提前结束后的写入拒绝测试 |
| 服务重启 | 重启后账号、会话、答案和场次进度仍可使用 | 实际重启测试 HTTP 进程及应用重建测试 |

每个账号每套卷仅一个场次，重复验收应使用新账号或独立测试数据库。未提交的选择不作为草稿保存。查看逐题结果可运行 `npm run db:results -- --all`。
