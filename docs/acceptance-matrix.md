| B3 两账号独立进度与答案，不能越权 | 场次所有权检查，`user_id` 约束和独立登录 Cookie | 双浏览器手工录屏；API 双用户读取/写入越权拒绝；浏览器独立上下文测试 | 已验证两用户规模与越权边界；不代表大规模并行容量 |
| B4 示例卷含单选多选，可提交、切题、正常交卷并查记录 | 开考快照、逐题事务写入、完成状态、本机只读结果命令 | 作答视频；`test_complete_business_flow_and_closed_exam` 对六题逐项保存及判分断言；真实浏览器完成六题 | 已验证完整链路；手工视频主要展示提前交卷，正常完成由自动化证明 |
| B5 刷新/重新进入恢复进度，计时及超时与说明一致 | 服务端持久化剩余预算；心跳在线扣时，恢复不补满；离线保留余额 | `test_refresh_and_server_restart_preserve_connected_budget_and_cookie`；`test_offline_refresh_longer_than_question_limit_never_skips`；浏览器刷新、离线刷新、探测失败、在线超时 | 已验证；未提交勾选不是草稿，刷新不保存；旧 v1 场次升级仅当前未提交题一次性初始化时限 |
| B6 提前/正常交卷，结束后不能再改本次答案 | 状态检查、写事务、答案唯一键、幂等交卷 | 提前交卷视频；API 提前交卷及正常结束后拒绝改写；浏览器完成恢复及提前结束后 409 | 已验证；最后一题响应丢失时可刷新恢复完成页，尚未专门优化即时错误提示 |
| B7 服务重启后账号、场次、答案仍在 | 文件 SQLite、迁移版本、认证会话持久化 | `test_real_process_restart` 实际重启自有 HTTP 子进程；应用重建恢复；v1 迁移与本机升级逐表比对 | 已验证本机进程重启和升级；不等同于磁盘故障、备份容灾或多机切换演练 |

上述源码均位于 `backend/tests/` 和 `tests/e2e/exam.spec.ts`，执行结果对应 [最新 JUnit/汇总](reports/offline-timer/summary.json)。账号验证和场次权限由后端执行，不以 localStorage 或固定成功响应替代。
