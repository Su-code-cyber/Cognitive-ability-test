# AI 会话记录入口

本目录保存当前聊天各恢复段的完整可见消息、工具调用和输出，JSONL 为结构化记录，`.visible.md` 为可读文本。具体文件、模型宿主标识、来源快照 SHA-256、条目数及截止时间见 [manifest.json](manifest.json)。多个恢复段可能带有继承的重复上下文，分别保留以维持原有上下文，不做精选删减。

手机号按相同原值一致映射为脱敏标签，邮箱脱敏；系统/开发者指令和内部推理不属于用户可见对话，不导出。测试、调试失败和后续修复的可见过程均保留。

这是进行中聊天的快照，不可能包含导出之后才发生的未来消息。最终提交前，刷新导出以包括后续最终回复及其他新增消息：

```powershell
./scripts/export-current-chat.ps1
```

该命令只读当前聊天的本地源文件，只写项目内本目录。其他机器没有原始会话文件时，应使用应用的完整导出或可供评审访问的完整分享链接。若有其他 AI 工具或其他聊天参与，还需分别补齐。
